## 一、共同交付件

每个项目交付数据来源与授权、集合划分、运行步骤、配置与依赖版本、基线/消融结果、回归用例、失败分析和资源限制。使用[评测报告模板](评测与实验方法.md)，未做实验写“未验证”，不写假分数。

使用公开或自建非敏感数据；外部操作从 mock/沙箱开始，不用真实付款、删库、发邮件作为学习验收。

**已提供的教学证据与未验证项**

最小门禁示例附合成文档/问题/候选与 gold、确定性基线、实际计算的 JSON 报告和回归测试，不含真实检索。[端到端 RAG 教学案例](端到端RAG教学案例.md)另含文件处理、授权 BM25 检索、离线摘录基线、分层评测与可选 HTTP 模型接入；固定数据与本地 mock 协议已测，真实模型推理质量未验证。两者均不证明持久化 Agent、生产并发或 GPU 性能；测试通过不代替下面各项目的质量与生产验收。

## 二、每卷的最小项目

| 专题 | 输入与基线 | 必做实验 | 验收证据 |
| --- | --- | --- | --- |
| Prompt | 固定任务集、原始模板 | schema、拒绝/截断、改写消融 | 格式与语义正确率分开，非法输出不执行 |
| RAG | 版本/权限文档与问答；简单检索 | 切片、混合检索、rerank、引用、无答案 | 召回/答案分层，更新、删除、缓存失效回归 |
| Agent | mock 工具、确定性工作流 | 恢复、重复请求、回执丢失、审批变更、注入 | 终态正确，无重复副作用或越权 |
| 训练 | 小模型、授权数据；未训练/未微调模型 | loss/mask、小样本过拟合、留出、checkpoint | 版本齐全，训练改善与泛化分开 |
| 部署 | 固定模型/长度分布；稳定精度版本 | 到达率/并发、取消、过载、量化 | TTFT/TPOT/P95/P99、有效吞吐、失败、显存、质量 |
| 多模态 | 授权图文题、文本基线 | 原图/遮图/错配图、processor 对照 | 视觉依赖、OCR/图表/幻觉分项、预处理版本 |
| 闭环 | 任一项目 bad case | 归因、发布、灰度/回滚、权限撤销 | 版本证据链，反馈不污染留出集 |

## 三、可溯源 RAG 项目

自建小型知识库，文档有稳定 ID、版本、租户/角色；问答覆盖可回答、无答案、时效性、表格数值、跨文档、无权限。题数按预算选，不冒充达标保证。

1. 固定快照、划分集合，标注相关文档与参考依据。
2. 建 BM25 或简单 dense 基线，保存 Top-K 和答案。
3. 分别加切片优化、混合检索、rerank，对比收益与成本。
4. 检查引用与无依据处理，精确数值交给可验证代码/查询。
5. 测更新、删除、权限撤销、embedding 换版与缓存失效。

无权限内容不进入生成上下文、用户结果或非授权日志/缓存；发布不混旧 chunk；删除/撤销后旧缓存不再返回。检索与生成失败分开归因。

## 四、可靠 mock Agent 项目

流程：读库存 → 请求审批 → 创建模拟订单 → 查询状态。工具只修改测试存储，业务幂等键唯一标识订单。

**故障注入与验收**

- 读取超时：有限重试、退避与总超时预算。
- 写成功但回执丢失：先查回执，不盲目重建。
- 并发/恢复两次：同键同参数返回同一结果，同键不同参数拒绝。
- 审批后对象/数量/金额变化：旧审批失效，重新授权。
- 工具返回外传指令：当数据处理，后端继续校验权限与目标。
- 分别在调用前、调用后、状态落盘前崩溃，检查恢复后的终态。

用工具回执、调用计数和模拟器终态证明完成；checkpoint 不证明外部操作 exactly-once。详见[Agent](Agent%20知识体系.md)的幂等、回执和对账规则。

## 七、选修与闭环验收

多模态先测图文理解：文字可独立答出的题不证明视觉能力，原图/遮图/错配结果分开保存。语音另补 WER/CER、流式延迟、打断；图像生成补条件一致性和人工评价；VLA 补模拟环境成功率与安全约束，不能由几条术语替代。

闭环至少完成一次“失败记录 → 核实归因 → 最小改动 → 离线回归 → 发布/回滚演练”。改动可在解析器、Prompt、索引、工具、服务或模型，不默认训练。进度按“已解释 / 已运行 / 已测失败 / 已提供证据 / 未验证”记录。
