## 一、张量、线性代数与概率

掌握矩阵乘法、转置、广播、求和维度；区分 batch、序列、特征、注意力头。理解条件概率、期望与方差，独立假设不是实际模型分布的保证。

检查题：token ID 为 $[B,T]$，嵌入矩阵为 $[V,d]$，查表结果为 $[B,T,d]$，最终 logits 为 $[B,T,V]$。这里 $V$ 是词表大小，不是注意力的值矩阵。能用小张量检查 `reshape` 与 `transpose`，阅读[PyTorch 基础](../01-环境搭建与Python基础.md)。

Softmax 将 logits 转为概率；实际计算先减去最大值，减少指数溢出。概率归一化不等于置信度已经校准。

## 二、自动微分与优化

- 掌握链式法则、计算图、梯度累积与清零、AdamW、学习率调度、权重衰减与裁剪。
- `eval()` 控制 Dropout 等行为，`no_grad()` 关闭梯度记录，两者不能互相替代。
- 分开监控训练和验证损失，训练 loss 下降不证明泛化提升。

**Dropout**

训练时以概率 $p$ 将激活置零，保留项按 $1/(1-p)$ 缩放，保持逐元素期望不变（倒置 Dropout）：

$$
\widetilde x_i=\frac{m_i x_i}{1-p},\quad m_i\sim\operatorname{Bernoulli}(1-p),\quad 0\le p<1.
$$

不是永久删除参数；标准推理模式不再随机置零。原始 Transformer 在子层输出进入残差相加前使用 Dropout，也用于嵌入与位置编码之和；现代模型的配置可能不同。阅读[优化器](../06-AdamW优化器实现.md)、[训练循环](../07-训练循环与损失函数.md)。

## 三、语言建模、损失与数据边界

输入前缀预测下一个 token。设 $m_{b,t}$ 表示是否参与 loss，则平均负对数似然为：

$$
\mathcal L=-\frac{\sum_{b,t}m_{b,t}\log p_\theta(x_{b,t+1}\mid x_{b,\le t})}{\sum_{b,t}m_{b,t}}.
$$

- logits 与 labels 只移位一次；部分模型 API 内部移位，数据侧不能重复移位。
- 按规则屏蔽 padding、SFT 非目标角色；有效 token 为零时跳过或报错。
- 相同 tokenizer、数据与 mask 下，困惑度为 $\exp(\mathcal L)$；换 tokenizer 不宜直接比较。
- 梯度累积按窗口内有效 token 总数加权，不简单平均长度不同的 microbatch loss 均值。
- Packing 明确是否允许跨文档关注；独立样本需正确 attention mask、位置和标签边界。EOS 不自动隔离注意力。

训练/开发集用于学习迭代，验证集用于有限方案选择，最终留出集用于最终报告；命名可以不同，用途必须隔离。按文档、实体、用户或时间分组去重，防止近重复跨集合泄漏。反复查看测试集并修改系统后，它就不再是干净留出集。

阅读[分词器](../02-BPE分词器原理与实现.md)、[去重](../15-数据过滤与去重.md)、[评测方法](评测与实验方法.md)。

## 四、Transformer 与注意力

对单头、忽略 batch，$X\in\mathbb R^{T\times d}$，$Q,K\in\mathbb R^{T\times d_k}$，$V\in\mathbb R^{T\times d_v}$：

$$
Q=XW_Q,\quad K=XW_K,\quad V=XW_V,
$$

$$
\operatorname{Attention}(Q,K,V)=\operatorname{softmax}\!\left(\frac{QK^\top}{\sqrt{d_k}}+M\right)V.
$$

Softmax 按键位置逐行计算。因果 mask 在未来位置为 $-\infty$，允许位置为 $0$；padding 另处理，避免一行全被屏蔽。

**为什么除以根号维度**

假设各 $q_i,k_i$ 独立、零均值、方差 1，且乘积项间不相关，则 $\sum_{i=1}^{d_k}q_i k_i$ 方差为 $d_k$，标准差为 $\sqrt{d_k}$。除以它后方差为 1，防止维度增大时 logits 尺度过大、Softmax 过早饱和。实际模型不严格满足假设；这是尺度归一化，不是单位向量归一化，也不保证不会饱和。

- RoPE 通常作用于 Q/K，不等于直接加位置向量到嵌入。
- MHA/GQA/MQA 改变 KV 头数；KV Cache 缓存已有位置 K/V，不是模型长期记忆。
- FFN、残差、归一化组成 block；Pre-Norm/Post-Norm 顺序不同。
- 自回归生成包含 prefill 和多步 decode，不是整个答案只需一次前向。

阅读[Transformer](../03-Transformer架构详解.md)、[多头与 RoPE](../04-多头注意力与RoPE.md)、[RMSNorm/SwiGLU/GQA](../05-RMSNorm-SwiGLU-GQA.md)。

## 五、数值与系统

- 区分 FP32/BF16/FP16/FP8/INT8 的范围、舍入误差和内核支持；低精度不自动加速整个系统。
- 容差比较算子结果，测试极端 logits、有限值、空输入与全屏蔽位置。
- 区分权重、梯度、优化器状态、激活、KV 显存；GPU 测时需预热、同步、记录 shape/dtype/硬件和重复次数。
- checkpoint 关联模型、优化器、调度、步数、随机状态、数据版本与读取位置；恢复 RNG 不代表任意多 worker/分布式数据流精确续跑。
