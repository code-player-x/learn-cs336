# 最小验收示例：证据门禁与工具终态

> 返回[总索引](README.md)。这是可运行的确定性教学例子，使用自建非敏感样本与 mock 存储，不调用模型、不做真实下单、不连接外部服务。它补充[实践清单](实践与验收清单.md)，不是完整 RAG/Agent 平台或质量基准。

## 一、运行与交付件

在仓库根目录运行，只依赖 Python 标准库；命令默认只向终端输出 JSON，不写文件：

```bash
python -m code.basic_study.knowledge_acceptance
python -m unittest discover -s tests -p 'test_knowledge_acceptance.py' -v
```

[示例代码](../../code/basic_study/knowledge_acceptance.py)内含合成文档、问题、候选回答、gold 结果与检查规则；[测试](../../tests/test_knowledge_acceptance.py)验证正常与失败路径。报告标记 fixture 版本，交付实验时另外记录代码提交和 Python 版本。

## 二、RAG：有引用不等于有证据

此例跳过解析、检索与 LLM 生成，使用固定候选文档/回答，专门测试**授权过滤 → 引用版本与原文校验 → 返回或拒答**。未授权文档先从证据中排除，不进入生成输入。所有语料都是教学数据，角色来自可信测试配置。

需要跑文件处理与真实检索时，继续[端到端 RAG 教学案例](端到端RAG教学案例.md)：离线 BM25 + 摘录基线，并提供显式 HTTP 模型接入。它复用此处的引用门禁，同时独立评测检索召回与答案证据覆盖。

| 样本 | 候选问题/回答 | Gold 结果 | 验证点 |
| --- | --- | --- | --- |
| supported | 普通商品多久内可申请退货？引用原句“普通商品签收后7天内可申请退货。” | 返回该原句 | 来源、版本与文本均匹配 |
| unsupported | 退货运费谁承担？候选“退货运费全免。” | 拒答 | 退货期限文档不支持运费结论 |
| unauthorized | 客户查询仅员工可读的审批阈值 | 拒答 | 文本即使正确，也不能绕过授权 |
| stale_version | 正确原句引用了错误版本 | 拒答 | 引用必须匹配当前证据快照 |
| mixed_claims | 正确期限与无依据的运费结论一起返回 | 拒答整个候选 | 不能仅去掉错误引用保留结论 |
| invented_source | 正确原句绑定不存在的来源 | 拒答 | 答案正确不等于引用正确 |
| empty_claims | 空候选 | 拒答 | 空集合不能因 all([]) 而通过 |

**基线与门禁对照**

不校验、直接发布候选的基线仅在 supported 样本上符合 gold；门禁应使七个 fixture 全部符合 gold。`baseline_matches_gold` 和 `matches_gold` 是运行时计算的测试断言结果，不是预填的模型成绩。

**适用边界**

校验器只允许完整原句的精确摘录，不能判断改写、多跳推理或语义蕴含；精确摘录也不证明资料本身真实、完整或与问题相关。这里故意选可确定验证的范围，不演示“通用幻觉检测器”。完整项目仍需检索召回、答案正确性、引用覆盖与权限更新的独立评测。

## 三、Agent：回执丢失不等于操作失败

固定任务是在 mock 存储创建两本 notebook 的订单，审批绑定 `(notebook, 2)`，幂等键为 `task-001`。流程不是自主规划模型，只演示工具可靠性合同。

1. 模拟写成功、响应丢失，调用抛出超时。
2. 按幂等键与期望参数查询，恢复已有回执。
3. 同键同参数恢复/重放，返回相同订单，不增加写入次数。
4. 审批后改数量，旧审批拒绝；同键换参数即使有新审批，也拒绝复用该键。
5. 检查存储中恰有一个参数正确的订单、写入次数为一；模型口头说“已完成”不代替存储证据。

报告中的 `orders`、`writes` 来自 mock 存储；`checks` 包括回执恢复、重放、参数绑定与空存储反例。终态和回执都要核对，不能只因存在任意订单就判任务完成。

**适用边界**

存储是单进程内存字典，不证明跨进程崩溃恢复、并发原子性或生产 exactly-once。审批 tuple 是可信测试输入，不是客户端可自行提交的授权。生产还需认证/租户边界、原子幂等记录、持久化、回执对账、审批有效期与恢复演练。

## 四、怎样理解运行结果

`passed: true` 仅表示这里的固定测试合同通过。它不证明真实 RAG 答案质量、真实 Agent 成功率、吞吐、并发安全或可用性；这些明确为**未验证**。完整实验按[评测报告模板](评测与实验方法.md)另交数据划分、模型/工具版本、基线、消融、失败样本与风险门禁。
