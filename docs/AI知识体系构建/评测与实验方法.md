# 评测与实验方法：从感觉到证据

> 返回[总索引](README.md)。业务阈值需要事先约定，本章不提供伪装成行业标准的统一及格分。

## 一、固定评测合同和数据划分

优化前写清任务、允许输入、期望输出、拒答条件、风险和预算；记录模型/Prompt/索引/工具/引擎版本，保留原始基线。

- 开发集用于 bad case 分析与迭代；验证集用于有限次方案选择，记录查看次数。
- 最终留出集冻结隔离，只用于最终报告，不持续优化 Prompt、检索或奖励模型。
- 线上样本单独采样、脱敏审核；用于调参/训练后进入开发/训练集合，另维护干净留出集。
- 同文档切片、同用户相似题、近重复题不得跨集合；时效任务按时间划分，固定知识快照。
- 权限样本包括允许/禁止；公开 benchmark 不替代业务分布，可能存在训练污染。

## 二、指标分层与分母

| 层次 | 指标 | 口径与区别 |
| --- | --- | --- |
| 检索 | Hit@K | 至少命中一个相关项的查询数 / 有相关标注的查询数，不是答案正确率 |
| 检索 | Recall@K | 前 K 个结果中相关项数 / 标注相关项总数；说明查询间平均方式 |
| 检索 | Precision@K | 前 K 个结果中相关项数 / K；不足 K 个结果时说明分母规则 |
| 检索 | MRR | 首个相关结果排名倒数的查询均值，无命中计 0 |
| 检索 | nDCG@K | 按分级相关性评价排序，明确 gain 和无相关项处理 |
| 生成 | 正确性 | 参考答案、确定性规则或人工 rubric，不等于文本相似度 |
| 生成 | 忠实度 | 结论是否被资料支持；资料错误时“忠实”仍可能不正确 |
| 引用 | 支持率 / 覆盖率 | 引用是否支持结论 / 需溯源结论是否有引用，分开统计 |
| Agent | 任务成功率 | 工具回执、测试存储/模拟器终态验证，不听模型自称完成 |
| 安全 | 越权/重复副作用/注入成功 | 按威胁类别统计，同时测正常请求误拒率 |
| 服务 | TTFT/TPOT/E2E | 首 token/逐 token/完整请求延迟，报告分位数与排队条件 |
| 成本 | 每个成功任务成本 | 含失败、重试、检索、评分、工具与资源，不只算最终回答 |

Context Precision/Recall 评价检索上下文；LLM Judge 分数是代理指标，不是事实真值。无答案、被权限屏蔽、未完成、超时单列，不静默删除让分数变好。

[最小验收示例](最小验收示例.md)演示用固定 gold、授权证据和 mock 存储判断结果。通过七个合成 fixture 只证明这些规则通过，不作为真实任务成功率或统计显著性的证据。

## 三、基线与消融

Prompt 用原始模板；RAG 对照直接回答与 BM25/简单 dense 检索；Agent 对照确定性工作流或单 Agent；部署对照稳定精度版本；训练对照未微调模型或同 token 预算训练。

一次改变一个关键因素，必要的联合改动补消融。固定请求集、数据快照、模型和预算，记录失败例，不只展示成功样本。量化质量和性能分开验收；不预设 rerank、多 Agent 或更大模型一定更优。

## 四、LLM Judge 校准

- 先定义人工 rubric：正确性、支持性、格式、危险行为分开评分。
- 按任务/难度抽样建立人工标签；关键样本双人标注并处理分歧。
- 固定评分器模型、版本、模板、温度、schema；盲评方案名，交换 A/B 顺序检查位置偏差。
- 报告人工一致率、混淆矩阵、误判类型；换评分器需重新校准。
- 数值、代码测试、工具终态优先用可验证规则，自评不是唯一验收。
- 被评答案是不可信数据，防止其指令劫持评分；评分输入也需脱敏和限制外传。

## 五、不确定性与配对比较

报告样本数、成功/失败计数、重复运行与波动。同题 A/B 配对比较；同文档/用户相关样本按组抽样，不假装独立。

以下仅用标准库演示配对 bootstrap；输入是独立样本的配对分数，不是生产实测，也不替代小样本分析。

```python
import random

def paired_bootstrap(a, b, repeats=2000, seed=7):
    if len(a) != len(b) or len(a) < 2 or repeats < 100:
        raise ValueError("need paired samples and enough repetitions")
    delta = [y - x for x, y in zip(a, b)]
    rng = random.Random(seed)
    estimates = sorted(
        sum(rng.choice(delta) for _ in delta) / len(delta)
        for _ in range(repeats)
    )
    return {"mean_delta": sum(delta) / len(delta),
            "ci95_percentile": (estimates[int(0.025 * repeats)],
                                estimates[int(0.975 * repeats)])}

print(paired_bootstrap([0, 1, 0, 1], [1, 1, 0, 1]))  # 仅演示
```

区间跨 0，证据不足以断言提升；不跨 0 也不保证业务值得。少量样本零事故不证明零风险；多次挑最佳方案产生选择偏差。随机生成任务需多 seed/重复采样并报告预算，不选最好的一次。

## 六、上线门禁与持续回归

事先约定质量回退容限、安全红线、P95/P99 延迟与失败率、资源与每个成功任务成本。严重安全漏洞不能与平均质量相抵；廉价但大量拒答不算优化。测取消、超时、限流、降级、恢复、审计和回滚。

离线通过再影子/小范围灰度，A/B 有停止规则、风险限额和回滚责任人。已确认 bad case 进入持久回归集，最终留出集另行维护。失败先归因，不立即加 Agent 或训练。
